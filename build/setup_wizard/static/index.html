6. MQTT & smart features (optional — leave broker blank to skip)

Enables brightness/screensaver/reboot control and sensor reporting over MQTT (e.g. from Home Assistant). Leave the broker field blank to run as a plain browser kiosk.

Optional sensors — only turn on the ones actually wired to this Pi. Each publishes to MQTT and can be flipped off any time by reopening this wizard (run kiosk-reconfigure).

7. Remote access

This image ships with a known default terminal/SSH password (ChangeMe-Kiosk1! for user kiosk) so it's reachable out of the box. Set your own below — recommended before this device touches any network you care about.

Paste a public key (e.g. the contents of ~/.ssh/id_ed25519.pub) to enable passwordless SSH into this kiosk. Leave blank to skip — you can always add one later by running kiosk-reconfigure again.
