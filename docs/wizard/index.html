Kiosk Setup Wizard

Answer these once, download kiosk-setup.json, drop it on the SD card. The kiosk sets itself up on first boot and goes straight to your dashboard.

  1. Flash the latest image from Releases with Raspberry Pi Imager or balenaEtcher.
  2. Fill in this page and download kiosk-setup.json.
  3. Copy the file to the SD card's bootfs drive (re-insert the card if the drive doesn't show), eject, and boot the kiosk.

Nothing you type leaves this page: the file is made in your browser. It holds your Wi-Fi and MQTT passwords until the kiosk reads it on first boot and deletes it. A short kiosk-setup-result.txt without passwords is left on bootfs so you can see what happened.
